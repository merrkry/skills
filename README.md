# skills

**My personal agent skills**

`skills/` holds one skill per directory, each with a `SKILL.md`. To install one with [yaasm](https://github.com/merrkry/yaasm):

```toml
[sources.merrkry-skills]
github = "merrkry/skills"

[skills.ship-it]
source = "merrkry-skills"
path = "skills/ship-it"
```
